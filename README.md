# 親孝行おにぎり 製造ボード試作品

受取時刻別・商品別だけの架空データ試作品。注文確認・電話タブ・実際の予約情報・Square通信は含まない。

製造数はブラウザに保存し、端末間では同期しない。

## GitHub Pagesへの公開

1. GitHubに新しい公開リポジトリ `oyakoko-production-demo` を作成する。
2. このフォルダの4つの画面ファイルとREADMEをリポジトリ直下へアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. Branchをmain、フォルダを / (root) にしてSave。
5. 公開完了後にPagesに表示されるURLを開く。

公開された画面はChatGPT・GitHubへのログイン不要。操作によってSquareへの注文や決済は発生しない。
